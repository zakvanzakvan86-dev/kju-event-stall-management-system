# KJC Event Stall & Startup Management System

A web-based stall and event management platform developed for Kristu Jayanti University (KJU).

This system helps event coordinators, students, startups, and administrators manage event stalls, registrations, approvals, payments, reports, and reimbursements digitally in a centralized platform.

## Main Features
- Event creation and management
- Student and startup stall registration
- QR-based payment handling
- Approval workflow system
- Stall allocation and tracking
- Automated email notifications
- Startup sales and report submission
- PDF and video upload support
- Reimbursement request processing
- Admin dashboard and analytics
- Consolidated report generation for documentation

## User Roles
- Admin
- Event Coordinator
- Student
- Startup/Participant
- Finance/R&D Approver
